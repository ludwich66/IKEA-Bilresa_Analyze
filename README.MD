IKEA-Bilresa Analyze


I drilled a hole in the bottom for a 4-pin female connector, but wanted to leave the housing as is.

WARNING: 
The space for wires is very limited. The housing has supports and a slot for the LED – it looks simpler than it is – you'll notice this when you clip it shut ;-) if you leave the housing as is.

1: Breakout all Buttons
- All Buttons are groundet, 
- Each Button has a Testpoint on the PCB
- Space is very limited
